# Windows Native Helpers

Esta pasta armazena localmente os binários auxiliares de captura WASAPI Process Loopback (`transync-win-process-loopback-helper.exe`) e Z-Order PiP (`transync-win-pip-z-order-helper.exe`).

Caso os binários não estejam presentes nesta pasta, o aplicativo faz fallback automático para `C:\Program Files\Transync AI\resources\win-native-helpers\`.
